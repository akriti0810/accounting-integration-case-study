# Go-Live Checklist

## Configuration and testing

- [ ] Finance approved GL, department, entity, and cash-account mappings
- [ ] Required fields and $1,000 approval threshold confirmed
- [ ] High-priority tests passed
- [ ] Exception owners validated their workflows
- [ ] Journal balances and eligible source records reconcile
- [ ] Sample import reviewed in a sandbox or non-production environment

## Enablement and launch

- [ ] User guide shared and owners trained
- [ ] Support contacts and escalation expectations documented
- [ ] Final source export and configuration version retained
- [ ] Import approved by Finance lead
- [ ] Failed validation or reconciliation stops the import
- [ ] Posted accounting total compared with approved export

## Post-launch measures

- Exception rate by category
- Percentage ready on first review
- Average exception resolution time
- Import failures or duplicate-posting incidents
- Recurring Finance support questions
